## About Me – The Caffeine-Coded Truth ☕

👨‍💻 I'm **Hrutik Chaudhari**, a Full Stack Software Engineer focused on building applications, integrating frontend workflows with backend APIs, and developing AI-powered products.

💼 At **Raja Software Labs**, I work on LinkedIn client systems, contributing to migration and integration work spanning **75+ production API routes** from a Java Play Framework monolith to Rest.li-based microservices. My work includes Ember.js/React frontend integration, functional-parity validation, API testing, browser debugging, log analysis, staged feature-flag/LIX rollouts, pull-request reviews, and legacy cleanup.

🚀 At **BrainSync Solutions**, I built a stakeholder-facing platform using React and a Python backend, then rebuilt and deployed it using MongoDB, Express.js, React, Node.js, and Redux as the requirements expanded. I also contributed to an AI-powered chatbot using Python, FastAPI, LangChain, and ChromaDB.

🤖 I built and deployed **MockMate**, a MERN-based AI mock-interview application that generates interview questions and provides structured evaluation and feedback. I’m currently implementing resume-grounded RAG using chunking, embeddings, vector search, and retrieved resume context.

💳 I’m also building **PayFlow**, an in-progress Node.js and Express payment-processing application focused on backend API design and reliable payment workflows.

🎯 I’m open to **Full Stack Software Engineer, MERN Developer, React Developer, Node.js Developer, Software Engineer, and AI-powered application development** opportunities.

☕ Give me a meaningful product problem, a clear API contract, and enough coffee—I’ll happily trace the complete flow until it works.
