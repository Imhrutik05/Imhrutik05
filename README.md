## About Me – The Caffeine-Coded Truth ☕

👨‍💻 I'm **Hrutik Chaudhari**, a Software Engineer who enjoys tracing a request from the UI and API contract through the business logic, service layer, and data flow.

💼 In my current role, I contribute to modernizing production systems by migrating and integrating **75+ API endpoints** from a Java Play Framework monolith to **Rest.li-based microservices**. My work includes preserving behavioural parity, integrating Ember.js consumers, testing authenticated APIs, and supporting feature-flag-based rollouts.

🤖 Outside work, I build **AI-powered full-stack applications** using React, Node.js, Python, MongoDB, LangChain, and LLM APIs—turning AI capabilities into usable product experiences.

🚀 I'm growing toward deeper backend engineering through **Spring Boot, SQL, Docker, distributed systems, cloud, DSA, and system design**.

☕ Give me a meaningful problem, a clean API contract, and enough coffee—I’ll happily keep debugging until the entire flow makes sense.
